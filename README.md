# CUSTOM DATA CLEANING AGENT.(Weekend Project)

This is a custom made data cleaning agent that corrects information on spreadsheet by accessing the gov.uk api. 
I made it when I was working on a data cleaning project to help fasttrack my work, ensuring I met the equired deadlines.

## Setup & Installation

### 1. Requirements
Ensure you have Python 3.10+, a Groq API Key and a gov.uk API key.

### 2. Install Dependencies
```bash
pip install requirements.txt
```
